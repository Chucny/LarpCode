# LarpCode
LarpCode is an open source IDE focused on vibecoding and LLM integration. It supports many different LLM windows including Claude, HuggingChat, GPT and GitHub Copilot.

### 💖Features
- Music playing: perfect for vibecoding
- Language syntax colour
- LLM support (pywebview windows)
- Mega TXT file merger (perfect for AI slop)
